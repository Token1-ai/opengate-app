Some contracts still can't be reached. This is almost always the explorer's site blocking/limiting requests that come from a page opened directly as a local file (file://...) rather than a real web address. To fix it, serve this file over a local address instead of double-clicking it:

1. Open a terminal in the folder that has this file.
2. Run: python -m http.server 8000
3. Open http://localhost:8000/zklitvm-tx-counter.html in your browser and click Refresh.
